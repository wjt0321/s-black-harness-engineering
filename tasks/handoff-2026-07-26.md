# Handoff — Agent Socket Registry v1

> Date: 2026-07-26
> Status: implementation complete; verification and commit pending

## Product Direction

Agent Runtime is an insertable multi-Agent control plane. Pi, Kimi Code, Claude Code, OMP, and QwenPaw Agent API are sockets; safety and audit mechanisms remain infrastructure rather than the roadmap's center of gravity.

Stage 66 Pi bound-runner migration is deferred security work. Do not resume it automatically.

## Delivered

- `agent_runtime/orchestration_socket.py` projects every `adapter_type=agent` entry from the existing adapter registry.
- `orchestration socket list` and `orchestration socket inspect <socket_id>` expose a shared socket schema.
- The Control Panel keeps its v1 shape and embeds `agent_sockets` under the existing adapters section.
- Current declared sockets: `pi-cli`, `kimi-code-acp`, `claude-code-acp`, `omp-acp`, `qwenpaw-agent-api`.

## Boundary

`availability=declared` is registry metadata only. Socket discovery does not start or contact Agents, perform process/session/network/quota probes, read secrets, write files or ledgers, or change routing/execution behavior.
