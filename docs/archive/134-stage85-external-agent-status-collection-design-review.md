# 134 — 阶段 85：外部智能体状态采集方案设计评审

> 状态：设计评审已完成；选定“宿主内被动采集并原子发布”方案，但实施仍被阻止。当前不实现状态采集器，也不产生真实状态。

## 1. 这项工作解决什么问题

阶段 84 已经实现了安全读取器，但固定状态文件目前没有可信程序负责生成：

```text
.runtime/external-agent-status/omp-acp.v1.json
```

阶段 85 的目标不是马上连接外部智能体，而是先回答：由谁采集状态、从哪里读取、会产生哪些副作用、怎样安全写入、如何证明采集器身份，以及哪些证据齐备后才允许实施。

评审结论是：

- 选择 **宿主内被动状态采集器**；
- 采集器属于已经运行的 QwenPaw 宿主，不由 Harness 启动；
- 只读取宿主已经拥有的 Runner 注册表内存状态；
- 不主动执行命令，不主动连接 ACP（智能体通信协议），不创建会话；
- 通过固定临时文件和原子替换发布状态快照；
- 由于宿主接口、采集器版本和可信身份尚未实测，当前禁止实施。

## 2. 方案比较

### 2.1 方案一：宿主内被动采集并原子发布

**决定：选中，但暂不允许实施。**

采集逻辑嵌入已经存在的外部智能体宿主生命周期，读取宿主本来就维护的 Runner 注册表。状态变化时发布一次；宿主运行期间最多每 5 秒发布一次心跳快照，使 15 秒有效期可以稳定维持。

优点：

- Harness 不启动第三个真实进程；
- 不需要主动连接 ACP；
- 不需要为了查询状态而创建会话、发送提示词或调用模型；
- 不需要新增长期独立服务；
- 与阶段 84 固定文件读取器直接匹配。

当前阻塞点：仓库中没有经过核验的 QwenPaw 宿主状态接口名称、版本和行为证据，也没有真实采集器包的版本与摘要。

### 2.2 方案二：Harness 启动固定状态命令

**决定：延后。**

该方案会成为第三个真实进程操作，必须重新完成可执行文件可信绑定、固定参数、单机租约、启动与终止审计、超时、输出限制和 Windows 进程树回收。当前没有相应授权。

### 2.3 方案三：Harness 主动连接 ACP 查询

**决定：延后。**

主动连接可能改变连接生命周期，也无法在当前证据下排除隐式会话创建、认证、网络访问或宿主状态变化。阶段 85 不允许进行握手或探测。

### 2.4 方案四：独立轮询服务

**决定：拒绝。**

该方案会新增长期后台服务，并扩大网络、凭据、恢复、部署和运维边界，不符合当前本地最小控制面的约束。

## 3. 选定的数据流

未来只有在解除实施阻塞后，数据流才允许是：

```text
已经运行的 QwenPaw 宿主
  -> 已核验的 Runner 注册表只读接口
  -> 固定字段归一化
  -> 严格快照校验
  -> 固定临时文件
  -> 刷盘
  -> 原子替换固定状态文件
  -> 阶段 84 读取器
  -> 中文界面安全投影
```

禁止的数据流包括：

```text
Harness -> 启动命令 -> 查询状态
Harness -> 主动连接 ACP -> 查询状态
采集器 -> 创建会话/发送提示词/调用模型
采集器 -> 读取凭据/访问网络
采集器 -> 写 Harness ledger
```

## 4. 固定发布边界

未来采集器只能使用以下固定路径：

| 用途 | 固定路径 |
|:---|:---|
| 正式快照 | `.runtime/external-agent-status/omp-acp.v1.json` |
| 临时快照 | `.runtime/external-agent-status/.omp-acp.v1.json.tmp` |
| 单写者租约 | `.runtime/external-agent-status/omp-acp.v1.publisher.lock` |

发布要求：

1. 取得独立的状态发布单写者租约；
2. 安全读取上一份有效快照；
3. 新 `generation` 必须等于上一有效 generation 加一；
4. 已有快照无效时禁止静默覆盖，必须由操作者处理；
5. 生成严格、无多余字段、最大 64 KiB 的 UTF-8 JSON；
6. 计算 canonical JSON 的 SHA-256 快照标识；
7. 固定临时路径必须通过 containment、普通文件、无链接/重解析点检查；
8. 写入临时文件并刷盘；
9. 写后重新解析并通过完整 schema、身份和大小校验；
10. 使用同目录原子替换正式快照；
11. 替换后再次校验正式文件；
12. 清理临时文件并释放租约。

任何步骤失败都不得留下 `complete=true` 的部分快照。

## 5. 状态来源与时间规则

唯一允许的数据来源是宿主已经维护的内存 Runner 注册表。采集器不得为了填充字段而主动查询其他进程、网络端点或 ACP 服务。

触发方式设计为：

- Runner 注册、移除或状态变化时事件触发；
- 宿主已经运行时，最多每 5 秒发布一次受限心跳；
- 不创建新的后台服务或独立进程；
- 宿主停止后不继续刷新，阶段 84 读取器会在 15 秒后将状态判为过期。

观察时间必须来自生成当前内存视图的同一时刻，不得使用文件时间、上一次心跳时间或外部服务时间代替。

## 6. 可信身份结论

当前阶段 84 binding 中的：

```text
producer_version = design-unobserved
```

只是“尚未观察到真实实现”的占位值，不是可信的进程身份证明。

快照中的采集器名称、版本和摘要都可以被同一用户伪造，因此**内容绑定不等于进程身份证明**。在以下证据齐备前，不得把快照用于派发决策：

1. 固定宿主状态接口的名称和版本；
2. 真实采集器包的版本和内容摘要；
3. 状态目录的所有者与访问控制清单审阅结果；
4. 崩溃恢复、租约、原子替换和写后校验测试工具；
5. 用户对采集器实施的再次明确授权。

即使未来这些证据齐备，状态快照仍只提供观察证据，不自动授予执行或派发权限。

## 7. 审计与日志边界

状态发布不是 Harness 的真实执行操作，因此选中方案不允许外部宿主写 Harness execution ledger。

可接受的追踪信息只存在于快照本身：

- generation；
- snapshot id；
- observed time；
- 固定采集器 binding；
- 无副作用声明。

如果未来改为由 Harness 启动进程或主动连接，则必须重新进入真实执行设计，遵守 started audit、唯一 terminal audit、租约、超时和进程树/连接回收要求。不能复用本设计绕过执行审计。

日志只允许输出稳定错误编号和安全中文提示，不得输出 Runner 原始内容、端点、进程号、会话标识、凭据或外部异常原文。

## 8. 失败处理

阶段 85 冻结以下错误编号：

| 错误编号 | 中文含义 | 处置 |
|:---|:---|:---|
| `collector_host_hook_unverified` | 宿主状态接口未核验 | 阻止实施 |
| `collector_identity_unbound` | 采集器身份未绑定 | 阻止实施 |
| `collector_host_not_running` | 外部智能体宿主未运行 | 状态不可用 |
| `collector_registry_unavailable` | Runner 注册表不可读取 | 状态不可用 |
| `collector_source_ambiguous` | 无法唯一绑定目标 Runner | 阻止发布 |
| `collector_lease_unavailable` | 单写者租约不可用 | 等待重试 |
| `collector_existing_snapshot_invalid` | 已有快照无效 | 禁止覆盖 |
| `collector_generation_conflict` | generation 无法安全前进 | 阻止发布 |
| `collector_temp_path_unsafe` | 临时路径不安全 | 阻止发布 |
| `collector_snapshot_too_large` | 快照超过 64 KiB | 阻止发布 |
| `collector_snapshot_validation_failed` | 待发布快照校验失败 | 阻止发布 |
| `collector_atomic_replace_failed` | 原子替换失败 | 保留旧快照并重试 |
| `collector_postcheck_failed` | 替换后校验失败 | 阻止继续使用 |
| `collector_cleanup_failed` | 临时资源清理失败 | 阻止下一次发布 |
| `collector_side_effect_boundary_violated` | 发生未授权副作用 | 立即停止并拒绝证据 |

所有错误只释放错误编号和固定安全提示。

## 9. 测试要求

未来实施前至少需要以下测试：

- 固定宿主接口只能读取已经存在的内存注册表；
- 无进程启动、无 ACP 新连接、无会话、无提示词、无模型调用；
- 无凭据读取、无网络访问、无独立后台服务；
- 单写者租约冲突；
- 上一快照缺失、有效、无效和 generation 冲突；
- 临时路径为目录、符号链接、重解析点或硬链接；
- 写入中断、刷盘失败、原子替换失败和进程崩溃；
- 最大尺寸、严格 JSON、schema、content id 和 binding；
- 写后校验和临时文件清理；
- 宿主停止后状态按 15 秒有效期自然过期；
- 所有失败不泄露原始内容或凭据；
- 阶段 84 读取器只能得到 observed、unavailable、stale 或 blocked，永不自动 ready。

真实采集器测试不能在没有再次授权时启动外部智能体或连接 ACP。

```text
design_complete = true

```
