# 135 — 下一里程碑：OMP/Pi 真实状态接入与中文控制面板展示

> 状态：入口已准备，尚未开始实施。开始前必须确认真实宿主接口并获得明确实施授权。

## 1. 里程碑目标

不再继续拆分纯设计小阶段。下一里程碑一次性完成下面这条可见链路：

```text
OMP/Pi 真实运行状态
  -> QwenPaw 宿主内状态采集器
  -> 固定原子状态快照
  -> 已完成的安全读取器
  -> 中文控制面板真实状态展示
```

用户最终应能在控制面板中直接看到：

- OMP/Pi 是否被宿主观察到；
- 当前状态是已连接、未连接、状态未知还是状态已过期；
- 最后观察时间；
- 状态证据是否有效；
- 为什么当前仍不能派发任务。

“已连接”只表示观察到 Runner，不代表模型可用、会话可创建或允许派发。

## 2. 必须一次性完成的工作

1. 核验 QwenPaw 宿主提供 Runner 注册表的真实接口名称、版本和只读行为；
2. 为真实状态采集器建立版本与内容摘要绑定；
3. 审阅 `.runtime/external-agent-status/` 的目录所有者和访问控制；
4. 实现宿主内被动状态采集器，不由 Harness 启动新进程；
5. 实现固定租约、generation 前进、临时写入、刷盘、严格校验、原子替换和写后校验；
6. 让阶段 84 读取器消费真实快照；
7. 将安全投影接入中文控制面板；
8. 完成真实但只读的联调和故障验收；
9. 更新恢复文档、操作说明和测试契约。

## 3. 验收标准

只有同时满足以下条件，下一里程碑才算完成：

- QwenPaw 宿主运行时，控制面板能在 15 秒有效期内显示 OMP/Pi 的真实观察状态；
- 宿主停止或不再发布时，状态自动变为“状态已过期”或“未连接”；
- 状态文件始终小于等于 64 KiB，并通过严格 schema、content id 和 binding 校验；
- 任意中断都不会让读取器接受半写快照；
- 采集器不启动额外进程、不主动连接 ACP、不创建会话、不发送提示词、不调用模型；
- 不读取凭据、不访问网络、不写 Harness ledger；
- 中文控制面板不显示原始输出、端点、进程号、会话标识或凭据；
- runner listed 仍只显示“已观察到，未证明就绪”，不授予派发权限；
- 专项测试、全量测试、doctor、public scan 和真实只读 smoke 全部通过。

## 4. 开始前阻塞条件

开始编码前必须取得：

- 可核验的 QwenPaw 宿主状态接口；
- 真实采集器实现位置和版本来源；
- 状态目录访问控制信息；
- 用户对实现和真实只读联调的明确授权。

任一条件缺失时，不得用猜测接口、主动命令探测或 ACP 握手代替。

## 5. 继续保持的停止线

下一里程碑不包含：

- 创建真实会话；
- 向模型发送提示词；
- 派发工作项；
- 自动多智能体协作；
- 网络服务、数据库或长期独立后台进程；
- 第三个 Harness 真实执行操作；
- 将状态证据解释为执行授权。
